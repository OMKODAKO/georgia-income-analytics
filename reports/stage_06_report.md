## 1. გაშვება
```bash
cd ~/Desktop/Georgia-Income-Analytics
.venv/bin/streamlit run dashboard/app.py
```

## 4. მეთოდოლოგიური დაცვა ინტერფეისში
- **2017–2019 და 2020–2025 არასდროს ერთიანდება** — პერიოდი ცალკე ირჩევა; დინამიკაში ორი ცალკე ხაზი და წყვეტის ხაზი.
- ყველა რიცხვი **ცოცხლად** ითვლება ბაზიდან, Stage 03–04-ის წესებით: შეწონილი; რამდენიმე წლისას წონა / წლების რაოდენობა;
  მედიანა ინტერვალის შიგნით ინტერპოლაციით; რეალური ₾ (2025).
- **მცირე შერჩევა:** <30 ერთ სქესში → შედეგი დამალულია და ჩანს გაფრთხილება; <100 → „*" და „დასკვნა არ კეთდება".
- ყველა გრაფიკს აქვს სათაური, ერთეული (₾) და წყაროს მითითება.
- **პროგნოზის ფორმა** მხოლოდ გამოგონილ პროფილზეა; ერთი და იგივე პროფილი ორივე სქესით — ნათლად წერია, რომ ეს
  მოდელის თვისებაა და არა მიზეზშედეგობრივი ეფექტი და არ გამოიყენება ინდივიდებზე გადაწყვეტილებისთვის.
- Stage 04–05-ის შედეგები ფაილებიდან იკითხება (ფილტრები მათზე არ მოქმედებს — ეს ეკრანზე წერია).

## 5. შემოწმება
- **ბრაუზერში** ყველა ჩანართი გაიხსნა და შემოწმდა; ფორმამ გამოგონილ პროფილზე (ბაკალავრი, პროფესიონალი, განათლება,
  თბილისი, 40 სთ) დააბრუნა ქალი 988 ₾ / კაცი 1,143 ₾ (13.6%).
- **ავტომატური ტესტები (16):**
  - პერიოდი ერთადერთია ყოველ გამოთვლაში; უცნობი პერიოდი უარყოფილია; გაერთიანებული წონა = საშუალო წლის წონა.
  - „მიმოხილვის" რიცხვები = Stage 03 (ქალი 756.02, კაცი 1014.40, სხვაობა 25.47% / მედიანა 28.78% — 2020–25;
    27.88% — 2017–19); წლიური სხვაობები = Stage 03.
  - ფილტრები სწორად ზღუდავს რიგებს; ერთი წლისას წლიური წონა გამოიყენება.
  - მცირე ჯგუფი (მაგ. „შეიარაღებული ძალები", 16 ქალი) — შეცდომის შეტყობინება, რიცხვები არ ჩანს; ცარიელი არჩევანი — გაფრთხილება.
  - აპლიკაცია ეშვება შეცდომის გარეშე; 6 ჩანართი; ფილტრი და პერიოდის გადართვა ცვლის შედეგს; პროგნოზის ფორმა მუშაობს.
