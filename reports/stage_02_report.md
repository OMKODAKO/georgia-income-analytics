## 8. შემოსავლის სტანდარტიზაცია (`reports/income_definitions.csv`)
| | LFS ხელფასი | HIES შემოსავალი |
|---|---|---|
| Currency | GEL | GEL |
| Period | ბოლო ნამუშევარი თვე | თვიური საშუალო (საანგარიშო კვარტალი) |
| Gross / Net | **Net** | როგორც მიღებულია (ნაღდი) |
| Unit | **ინდივიდუალური** | **საოჯახო** |
| ფორმა | ინტერვალი (`income_lower`, `income_upper`) + თანხის შეფასება | თანხა |
| Nominal / Real | ორივე | ორივე |

- **თანხის შეფასება ინტერვალიდან** (მხოლოდ აღწერითი მიზნით; Stage 04-ში interval regression):
  დახურული ინტერვალი → შუა წერტილი; პირველი (0–100] → 50; ღია ზედა ინტერვალი (>2000) → **Pareto**:
  `α = ln((f₁₅₀₀₋₂₀₀₀ + f>2000) / f>2000) / ln(2000/1500)`, `mean = 2000·α/(α−1)` ყოველ წელს ცალკე.
  შედეგი: α = 2.5–4.2, საშუალო 2,634–3,322 GEL (`reports/pareto_top_band.csv`). Top band-ის წილი 0.7% (2017) → 4.1% (2025).
- **საერთო ინტერვალები** (`band_code_common`): 2020–25-ის 12 ინტერვალი ზუსტად ჯდება 2017–19-ის 9-ში — მხოლოდ შესადარებლად.
- **ინფლაცია:** Geostat-ის ოფიციალური CPI (2010=100, საქართველო, თვიური). **საბაზისო წელი 2025** (ბოლო სრული წელი).
  `real₂₀₂₅ = nominal × CPI̅₂₀₂₅ / CPI̅_year`, CPI̅ = 12 თვის საშუალო. კოეფიციენტები: 2017 → 1.494, 2020 → 1.320, 2024 → 1.039.
  CPI ემთხვევა ოფიციალურ წლიურ ინფლაციას 2018–2025 (ტესტი 06). წლიურ↔თვიური გადაყვანა არ გაკეთებულა.

## 11. პრობლემები და შეზღუდვები
1. ხელფასი მხოლოდ **ინტერვალია** → თანხა შეფასებაა (midpoint/Pareto); ზუსტი ანალიზი — interval regression.
2. **Non-response იზრდება** (23% 2025-ში, კაცებში მეტი) და 2023-დან უარი ცარიელად ინახება → შერჩევის მიკერძოების რისკი.
3. მხოლოდ **დაქირავებულები**; თვითდასაქმებულთა შემოსავალი არ არის.
4. **სამუშაო გამოცდილება არ არის** → `potential_experience` = ასაკი − სწავლის წლები − 6 (სწავლის წლები მიახლოებითია).
5. 2017–19-ში UID იცვლება ყოველ კვარტალს → ოჯახის კლასტერი მხოლოდ კვარტლის შიგნით; 2020+ `DiaryID` სრულია.
6. Strata/PSU არ არის → design-based SE მხოლოდ მიახლოებით.
7. HIES: 1,352 ოჯახი უფროსის გარეშე (ოჯახის უფროსის სქესის ანალიზში არ შევა), 2 შეუძლებელი უარყოფითი თანხა.
8. 2025 წლის Pareto α = 4.15 (უფრო „თხელი" კუდი) — top band-ის წილი იზრდება, sensitivity შემოწმება საჭიროა.
9. რაჭა-ლეჩხუმი იმერეთთან გაერთიანდა შედარებადობისთვის — ცალკე რეგიონული ანალიზი მხოლოდ 2019+ წლებზე.
