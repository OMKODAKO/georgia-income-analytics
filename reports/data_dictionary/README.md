# Data Dictionaries (Stage 01)

Generated by `src/data_dictionary.py` from the raw SPSS metadata and data profile — not typed by hand.

| File | Dataset | Rows |
|---|---|---|
| `lfs_data_dictionary.csv` | Labour Force Survey 2017–2025 | one per (table, variable) |
| `hies_data_dictionary.csv` | Household Incomes and Expenditures Survey 2017–2025 | one per (table, variable) |
| `official_aggregates_data_dictionary.csv` | Geostat wage / GPG / CPI tables | one per Excel sheet |

Columns
- **Variable_Name** — original name in the file
- **Table** — harmonised table name (e.g. `LFS_ECSTAT_ENG_2023` → `ecstat`)
- **Meaning** — SPSS variable label (latest year)
- **Data_Type** — SPSS storage type and measure; pandas dtype
- **Possible_Values** — value labels (latest year) or numeric range across years; codes found in data without a label
- **Missing_Values** — system-missing share by year; non-response codes (refused / don't know / not applicable); SPSS user-missing
- **Years_Present**, **Cross_Year_Status** (`identical`, `wording_only`, `LABEL_CHANGED`, `CODES_CHANGED`, `TYPE_CHANGED`)
- **Unit_or_Level** — person / household / … (never mix household and individual income)
- **Source** — Geostat listing page (per-file URLs + SHA-256 in `data/raw/manifest.json`)
- **Notes** — verified notes on the key variables (gender, income, period, currency, weights)

Missing shares are over all rows of the table: e.g. earnings are asked only of employees,
so ~75 % of 15+ persons are “missing” by design.
